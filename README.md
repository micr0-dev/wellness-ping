# Wellness Ping

A simple dead man's switch service. Get pinged regularly to confirm you're okay. If you don't respond, your emergency contacts get alerted.

[https://wellness-p.ing](https://wellness-p.ing)

## v2.0 — Built from Your Requests

The community asked, and we delivered. Every feature in v2.0 came from the original viral thread (55 messages, 54 replies) and GitHub issues.

### v2.0 Features

**Safety & Security:**
- Duress PIN — If forced to check in, enter your duress PIN to silently alert contacts
- 2FA with Authenticator App — Require a code from your authenticator app to check in
- Vacation / Travel Pause — Disable checks for a set period with auto-reenable

**Notification Channels:**
- Signal support — Coming soon (email can be the weakest link)
- HTML emails — Hyperlinked alerts that work in all email clients

**Customization:**
- Custom messages — Your contacts get the words you want them to read
